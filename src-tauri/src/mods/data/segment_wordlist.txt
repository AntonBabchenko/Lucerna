# Lucerna word-segmentation dictionary — project-owned data, CC0.
#
# A curated list of common English words plus Minecraft-domain stems, used to
# split a "slammed" Forge mod-id (e.g. "farmersdelight") into a spaced search
# query ("farmers delight") so the real mod surfaces on Modrinth/CurseForge,
# whose search engines tokenize the hyphenated slug. This is NOT third-party
# data — it is authored and maintained by the Lucerna project, so it carries no
# external license or provenance obligation.
#
# Format: one lowercase word per line. Lines starting with '#' and blank lines
# are ignored. Keep it clean of noise fragments (e.g. "kin", "ers", "ing") and
# bare 1-2 letter pieces: every entry can become a segmentation boundary, so a
# junk entry produces a junk split. When a popular mod-id should NOT split
# (its slug already has no hyphen, e.g. "waystones"), add the whole word so the
# longest-cover heuristic keeps it intact.
#
# Honest limit: ambiguous splits and non-English / invented mod-ids will not
# segment cleanly and stay Unresolved — that is the documented best-effort
# boundary of this feature, not a bug.
